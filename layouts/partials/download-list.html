Der grosse Vorteil: um ein neues PDF hinzuzufügen, muss man NICHTS in einer Textdatei eintragen - einfach die PDF-Datei in den richtigen Ordner unter assets/ hochladen, und sie erscheint beim nächsten Bauen der Website automatisch in der Liste (siehe docs/WARTUNG.md, Abschnitt "Wie füge ich ein PDF hinzu?"). Parameter, die diese Datei erwartet: path - Ordnerpfad relativ zu assets/, z.B. "downloads/kursskripte" page - die aktuelle Seite (wird für die Sprache gebraucht) AUFGABE + LÖSUNG als EIN Eintrag: Heisst eine PDF-Datei genau wie eine andere plus die Endung "_Loesung" (z.B. "2026_MusterZuordnen_A2.pdf" und "2026_MusterZuordnen_A2_Loesung.pdf"), werden beide zu EINEM Listeneintrag mit zwei Knöpfen ("Aufgabe" + "Lösung") zusammengeführt, statt als zwei getrennte Zeilen zu erscheinen. Eine Datei ohne passendes "_Loesung"- Gegenstück (z.B. weil Aufgabe und Lösung schon in einer einzigen PDF-Datei zusammen stecken) erscheint weiterhin ganz normal als einzelner Eintrag - in dem Fall am besten über data/downloads.yaml einen Anzeigenamen setzen, der klarmacht, dass die Lösung schon enthalten ist (z.B. "... (inkl. Lösung)"). Kein "Fehler melden"-Knopf mehr pro einzelnem Download: dafür gibt es stattdessen das eine allgemeine Fehlerformular auf der Übungsaufgaben- Übersicht (siehe report-error-general.html), das dieselbe Aufgabe für die ganze Sammlung auf einmal übernimmt, statt bei jeder einzelnen PDF-Datei ein eigenes kleines Formular zu zeigen. ============================================================================ */}} {{- $folder := .path }} {{- $page := .page }} {{- $site := $page.Site }} {{- $lang := $site.Language.Lang }} {{- $overrides := $site.Data.downloads.overrides }} {{- /* Alle PDF-Dateien im angegebenen Ordner finden, neueste (alphabetisch letzte, meist die mit der höchsten Jahreszahl im Namen) zuerst. */ -}} {{- $files := resources.Match (printf "%s/*.pdf" $folder) }} {{- $files = sort $files "Name" "desc" }} {{- if eq (len $files) 0 }} {{- /* Kein Fehler, wenn der Ordner leer ist - einfach ein freundlicher Hinweistext */}}
