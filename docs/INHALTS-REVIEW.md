# Inhalts-Review – wer hat welche Seite schon geprüft?

Bevor die Website live geht, soll jede Seite von **3 verschiedenen Personen**
gegengelesen werden (Vier-Augen-Prinzip reicht bei einer Website mit
medizinisch/rechtlich relevanten Informationen nicht ganz – deshalb hier
**sechs Augen**, also 3 Leute pro Seite). Geprüft wird: Ist der Inhalt
korrekt? Ist er verständlich? Fehlt etwas? Ist die Übersetzung (FR/IT)
sinngemäss richtig?

## Wie trage ich mich ein?

1. Diese Datei auf GitHub öffnen: [`docs/INHALTS-REVIEW.md`](https://github.com/Kroeppster/nc-wiki/blob/main/docs/INHALTS-REVIEW.md)
2. Auf das Stift-Symbol (✎ "Edit this file") oben rechts klicken.
3. In der Tabelle unten deinen Namen in eine freie Spalte (`Prüfer:in 1/2/3`)
   der Seite eintragen, die du kontrollierst. Wenn alle 3 Spalten einer Zeile
   ausgefüllt sind, gilt die Seite als geprüft – dann in der Spalte `Status`
   `✅ geprüft` eintragen.
4. Unten bei "Commit changes" **"Create a new branch for this commit and
   start a pull request"** wählen (nicht direkt in main speichern – gleiches
   Vorgehen wie in [`WARTUNG.md`](WARTUNG.md#8-wie-lösche-ich-eine-datei)
   beschrieben) und die PR öffnen. Kein technisches Wissen nötig, nur Text in
   die Tabelle eintragen.

Wenn dir beim Prüfen ein Fehler auffällt, kannst du ihn entweder gleich selbst
korrigieren (gleiche PR) oder als Kommentar in der Spalte `Notizen`
festhalten, damit jemand anderes es beheben kann.
